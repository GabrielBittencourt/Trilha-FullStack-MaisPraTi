# Multi App

Este é um aplicativo multi-funcional que inclui um gerador de QR Code, um buscador de IP, um motor de busca de filmes, um aplicativo de tarefas, um aplicativo de quiz e um tradutor de idiomas.

## Funcionalidades

- **Gerador de QR Code**: Gera códigos QR a partir de texto.
- **Buscador de IP**: Busca informações sobre um endereço IP.
- **Motor de Busca de Filmes**: Busca informações sobre filmes.
- **Aplicativo de Tarefas**: Permite gerenciar tarefas.
- **Aplicativo de Quiz**: Um quiz simples com perguntas e respostas.
- **Tradutor de Idiomas**: Traduz texto entre diferentes idiomas.

## Tecnologias Utilizadas

- React
- Node.js
- Express
- JWT para autenticação
- Axios para requisições HTTP
- Styled-components para estilização

## Como Executar

1. Clone o repositório.
2. Navegue até o diretório do servidor e instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor:
   ```bash
   node server.js
   ```
4. Navegue até o diretório do cliente e instale as dependências:
   ```bash
   npm install
   ```
5. Inicie o aplicativo React:
   ```bash
   npm start
   ```
